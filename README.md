# Opal

Лаунчер для Minecraft, который я делаю для себя и друзей. Надоело, что в одних лаунчерах куча рекламы, в других моды ставятся через танцы с бубном, поэтому собрал свой.

## Что умеет

**Любая версия игры.** От самых старых до свежей 26.3. Java лаунчер подбирает и качает сам, ничего ставить руками не надо.

**Моды в пару кликов.** Fabric, Forge, NeoForge и Quilt. Каталог модов, ресурспаков, шейдеров и готовых сборок прямо внутри лаунчера (Modrinth и CurseForge). Нужные библиотеки подтягиваются сами. Скачал мод с другого сайта? Просто перетащи файл в окно или вставь ссылку, лаунчер сам разберётся, что это и куда положить.

**Игра с друзьями.** Открываешь мир, друг заходит. Без аренды сервера.

**Кнопка «Ускорить игру».** Одним нажатием ставит Sodium, Lithium и ещё несколько модов на FPS. На слабых компах разница очень заметна. Миры и настройки при этом не трогает.

**Гардероб.** Скины, плащи, шапки, очки, маски, рюкзаки. Можно примерить на 3D-модельке и загрузить свой скин. Работает и без лицензии.

**Визуалы.** Стеклянный инвентарь, сундуки, кнопки и свой прицел. Цвет и прозрачность настраиваются.

**Удобные мелочи.** Отдельные сборки под разные версии и наборы модов, журнал игры с понятным объяснением, если она вылетела, вход через Microsoft или просто по нику.

## Premium

Лаунчер бесплатный. Есть подписка Premium за 99 ₽ в месяц: она открывает визуалы и самую красивую косметику. Оплату внутри лаунчера ещё доделываю, пока Premium включается промокодом.

## Как поставить

1. Скачай `Opal-Setup-0.2.0.exe` из раздела [Releases](../../releases/latest).
2. Запусти. Windows может написать «Система защитила ваш компьютер», потому что приложение новое. Нажми «Подробнее» → «Выполнить в любом случае».
3. Введи ник и жми «Играть».

Нужна Windows 10 или 11, 64 бита.

## Если что-то не работает

Пиши во вкладку [Issues](../../issues), постараюсь починить. Проект свежий, баги будут.
